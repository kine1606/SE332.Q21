REST API (nested data)

To get countries and languages, REST often becomes multiple endpoints / multiple requests.
GET /countries # then for each country: GET /countries/{code}/languages
This can turn into the “N+1 requests” problem.

GraphQL (nested query)

One request can ask for nested related data in one response.
POST https://countries.trevorblades.com/ query { countries { code name languages { name } } }
You control the shape of the returned JSON by editing the query.
