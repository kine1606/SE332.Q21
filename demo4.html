REST API (docs are external)

REST usually relies on separate documentation (Swagger/OpenAPI) rather than a queryable schema.
GET /openapi.json GET /docs GET /swagger
Docs can drift if not maintained.

GraphQL (introspection)

One request can query the schema itself using __schema and build docs from it.
POST https://countries.trevorblades.com/ query { __schema { queryType { fields { name description } } } }
This demo renders a small docs view from the response.
