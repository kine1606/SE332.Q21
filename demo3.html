REST API (typical approach)

To compare two countries, REST often becomes multiple requests.
GET /countries/VN GET /countries/JP
You have to merge results on the client.

GraphQL (aliases + fragments)

One request can fetch both countries. Aliases avoid key collisions, fragments reuse field selections.
POST https://countries.trevorblades.com/ fragment CountryDetails on Country { name capital currency emoji } query CompareCountries($code1: ID!, $code2: ID!) { countryA: country(code: $code1) { ...CountryDetails } countryB: country(code: $code2) { ...CountryDetails } }
Returned JSON keys are countryA and countryB.
